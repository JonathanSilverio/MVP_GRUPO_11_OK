## 📌 Situação-Problema Escolhida

**[Circuito Terê Verde] - Plataforma “Terê Verde Online”**

 A solução digital busca facilitar o acesso a informações sobre biodiversidade, trilhas, cachoeiras, eventos e condições das atrações naturais do Parque Nacional da Serra dos Órgãos, Parque Estadual dos Três Picos e Parque Natural Municipal Montanhas de Teresópolis.

## 🛠 Tecnologias Utilizadas

Descrição resumida das principais tecnologias aplicadas no desenvolvimento do MVP:

* HTML/CSS – Estruturação, estilização e comportamento das páginas.

* Framework Front-end (ex.: React) – Para construção da interface amigável e responsiva.

* JavaScript (Node.js/Vanilla) (Linguagem de programação utilizada para implementar a lógica de comunicação assíncrona, manipulação de dados, funções de CRUD, autenticação e consumo da API do Supabase).

* Supabase (Plataforma Backend-as-a-Service baseada em nuvem).

* PostgreSQL (Banco de dados relacional hospedado e gerenciado pelo Supabase).

* SQL (Linguagem de consulta e gerenciamento de banco de dados, utilizada para criação de tabelas e políticas de segurança).

* Row Level Security (RLS) (Políticas de segurança de nível de linha do PostgreSQL para controle de acesso às operações de SELECT, INSERT, UPDATE e DELETE).

* Supabase JavaScript Client (@supabase/supabase-js) (Biblioteca utilizada para fazer a ponte de comunicação e integração entre o front-end e o banco de dados).

## 🧪 MVP Definido

Desenvolvimento de um website funcional contendo:

- Página informativa sobre os parques e atrativos.

- Listagem de trilhas, cachoeiras, eventos e informações de biodiversidade.

- Sistema básico de login para administradores.

- Área administrativa para atualização de informações e gestão de disponibilidade. 

## 🎯 Objetivos e Benefícios do Produto

**Objetivos**

* Facilitar o acesso rápido e centralizado às informações dos parques.

* Oferecer uma plataforma intuitiva e atualizada para turistas e moradores.

* Possibilitar que administradores atualizem dados de forma segura.

* Promover a educação ambiental e o turismo responsável.

**Benefícios**

Maior comodidade para visitantes planejarem suas visitas.

Informações em tempo real sobre disponibilidade, clima e atrações.

Incentivo ao ecoturismo organizado e sustentável.

Apoio à comunidade local por meio da divulgação dos parques.


## 🎯 Público-Alvo

Turistas interessados em trilhas, montanhismo e ecoturismo.

Moradores da região que querem acompanhar eventos e novidades.

Estudantes e pesquisadores buscando informações sobre biodiversidade.

Administradores responsáveis pela gestão dos parques.

## 😣 Dores do Público-Alvo

Liste os principais problemas enfrentados pelo público:

Dificuldade em encontrar informações atualizadas sobre trilhas e atrações.

Falta de uma fonte centralizada sobre eventos e condições dos parques.

Planejamento prejudicado devido à ausência de dados de disponibilidade.

Pouca clareza sobre horários, temporadas e restrições.
